Description

The goal of the subject is to demonstrate what is programming and how computer programs are made. Presenting the basic concepts and constructs of programming it aims at building basic level programming skills. Building and developing problem-solving and algorithmic skills necessary for programming is also a key objective of the subject. The following main topics are covered using a high-level programming language that supports procedural programming (e.g., C, C++, Python, Java, C#):

  • Types, literals
  • Operators, expressions
  • Variables, assignment
  • Statements
  • Control structures
  • Basic data structures of the programming language of the course (e.g., arrays, lists)
  • Functions
  • Basic I/O
  • Other basic features of the programming language of the course (e.g., pointers)
  • Writing simple programs
  • Steps of creating executable programs
  • Errors and bugs, debugging
  • Basic level use of developer tools (e.g., an integrated development environment)

Laboratory

Instructors

Beregi-Kovács Marcell Dr. Biró Piroska

Weekly schedule

  1. week: Pre-testing.
  2. week: Basic level use of developer tools. Writing simple programs, steps of creating executable programs.
  3. week: Types, variables. Literals, operators, expressions.
  4. week: Control structures, statements.
  5. week: Loops, strings.
  6. week: Lists.
  7. week: Professional Week
  8. week: Midterm test
  9. week: Functions.
  10. week: Implementing basic algorithms.
  11. Week: Sets, dictionaries.
  12. week: Tuples. Implementing basic algorithms (searching, sorting).
  13. week: Files. Command line arguments.
  14. week: Endterm test

Lab Attendance

  1. Students are expected to attend all classes, anyone who is absent from more than three classes will not get a signature at the end of the semester. Missed classes are counted from the first week of the semester (beginning September 8, 2025).

  2. This also applies to students arriving in the country for any reason (e.g., visa problems) after the beginning of the semester.

  3. Each student must attend the class for which he or she has registered in Neptun.

  4. Students arriving at the classroom after the 15th minute of the class will be counted absent.

  5. In the classroom, going in and out (for any reason) is not allowed. Note that this is an inappropriate and unpolite manner that disturbs teaching. In this case, the instructor reserves the right to count you absent.

  6. When a student is counted absent, he or she is still allowed to stay in the classroom.

  7. However, there is no way to make up a missed class.
